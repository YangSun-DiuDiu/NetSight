### 链路验证结论

```
POST /alert/event/manual
  → EventCenterService.manualEvent()
    → eventMapper.insert() 事件入库
    → dispatchManual()
      → channelService.dispatch() [rule==null,走dispatchByChannelIds]
        → notifyChannelService.resolveChannels([4])
          → 查notify_channel id=4
          → TokenCrypto.decrypt(config_json) 解密AES配置
          → 装配channelId/type/name/config
        → channelRegistry.get("aliyun_sms")
          → AliyunSmsChannelSender.send()
            → 调用阿里云短信API
            → 返回消息ID
        → logMapper.insert() notification_log
```

**结论**：通道实例发送链路（通道管理→配置加密存储→运行时解密→Sender调用外部API→日志落库）全链路验证通过，阿里云短信和PushPlus两个通道均真实发送成功。
