02 — Components

双边框嵌套，
如玻璃置于托盘。

所有卡片均采用「外壳 + 内芯」双层嵌套：外壳半透明发丝线，内芯独立底色与内高光，超大圆角同心收束。

Double-Bezel 嵌套架构

外壳：`bg-white/4` 半透明底 + `ring-white/10` 发丝线 + 2px 内衬 + `rounded-30`。内芯：独立 `#0D0D10` 底色 + `inset 0 1px 1px` 内高光 + 同心圆角。任何卡片、输入框、特征网格都不允许平铺在背景上。

嵌套示例Outer Shell → Inner Core，双层同心圆角
Doppelrand · 同心曲线

磁吸按钮物理

按钮整体按压缩放 `scale(.98)`，内嵌箭头圆环斜向位移放大，形成内部动能张力。过渡一律使用自定义 cubic-bezier，拒绝 linear。

细线图标语言

仅使用超细描边（1.4px）、精确线条的线性图标（Phosphor Light / Remix Line 风格），内联 SVG 渲染，拒绝粗体图标库。

Ultra-Light Stroke

宏大留白纪律

区块留白 `py-110 ~ py-150`，宏观留白加倍。标题前置 10px 微型胶囊徽标，字号追踪 0.24em。

Macro-Whitespace · py-110

「昂贵」是可执行的规则

从字体、图标、边框、阴影到动效曲线，每一个「廉价默认值」都被显式封禁；每一处细节都被编码为可复用的架构模式。最终整体观感是 15 万美元级代理作品，而非「套了漂亮字体的模板」。

No Inter · No Roboto No 1px Gray Border No Linear Easing
03 — Motion

流体动效，
模拟真实物理。

所有过渡使用自定义 cubic-bezier 质量弹簧曲线；只动 transform / opacity；blur 仅用于 fixed/sticky 元素。

质量弹簧曲线

默认 `cubic-bezier(.32,.72,0,1)`，接近真实世界的质量与弹簧物理，拒绝 linear / ease-in-out。

交错遮罩展开

导航展开时，链接逐条从隐形盒子中淡入上滑（`translate-y-12 → 0`），每项 100ms 级差错峰。

滚动重模糊淡入

元素进入视口执行 800ms+ 的重度淡入（位移 + 模糊衰减），由 IntersectionObserver 驱动，绝不用 scroll 监听。
