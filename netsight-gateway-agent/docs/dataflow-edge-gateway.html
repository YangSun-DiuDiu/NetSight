图例说明：蓝实线=采集 / 探测链路（下行：清单下发 → 探测目标）　橙实线=告警链路（上行：指标 → 规则 → 告警）　红实线=告警投递（AM → nams-agent → 云端）　虚线=文件 / 配置依赖。当前 8 台设备：3 在线（绿）/ 5 离线（红）。

配置校验：promtool check config /etc/prometheus/prometheus.yml · promtool check rules /etc/prometheus/rules/nams_device_rules.yml · amtool check-config /opt/alertmanager/alertmanager.yml

热重载：kill -HUP $(pgrep prometheus) · kill -HUP $(pgrep alertmanager) —— 改配置无需重启
